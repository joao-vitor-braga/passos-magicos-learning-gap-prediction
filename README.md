# passos-magicos-learning-gap-prediction
Machine learning system that predicts a student's risk of falling behind grade level (learning gap) in the following year, using longitudinal PEDE indicators (2022-2024) from Associação Passos Mágicos. Includes EDA, a Gradient Boosting model (AUC-ROC 0.83), and a Streamlit app for individual and batch predictions.
